# trabajo-integrador
Sistema de Gestión de Países
Descripción

Este programa fue desarrollado en Python y permite administrar información de diferentes países.

Los datos que se pueden guardar son:

Nombre del país.
Población.
Superficie.
Continente.

La información se almacena en un archivo llamado paises.csv.

Funcionalidades

El programa permite:

Agregar países.
Actualizar países.
Buscar países.
Filtrar por continente, población y superficie.
Ordenar por nombre, población y superficie.
Mostrar estadísticas.
Mostrar todos los países.

Requisitos
Tener instalado Python 3.
Tener los archivos main.py y paises.csv.

Instrucciones de uso
Descargar el proyecto de GitHub.
Abrir la carpeta del proyecto.
Abrir una terminal.
Ejecutar el siguiente comando:
bash
python main.py
Seleccionar una opción del menú e ingresar los datos solicitados.

Ejemplos de entrada y salida
Agregar un país:
Entrada:
text
Seleccione una opción: 1
Nombre: Argentina
Población: 46000000
Superficie en km²: 2780400
Continente: América
Salida:
text
País agregado correctamente.
Mostrar países:
Entrada:
text
Seleccione una opción: 7

Salida:
Se muestra una tabla con el nombre, población, superficie y continente de los países registrados.
